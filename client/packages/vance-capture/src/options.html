In Vancetope, open the link list, press ⚙, create a capture token and copy the string it shows once.

A string for a destination that is already listed renews it in place — the name and the folder above are kept. The token is pinned to the project, not to one list: a changed folder reaches another link list in the same project. Revoking is done in Vancetope, under the ⚙ of the link list.
