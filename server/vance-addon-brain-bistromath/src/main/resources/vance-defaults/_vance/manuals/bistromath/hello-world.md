# Hello World

Three documents in one folder. `bistromath_app_create(folder="apps/hello",
title="Hello")` writes exactly this — read it before writing your own.

```
apps/hello/
  _app.yaml     the manifest
  main.yaml     a view
  main.js       the program
  _index.md     generated by app_rebuild — what the runtime found
```

## `_app.yaml`

```yaml
$meta:
  kind: application
  app: custom
title: Hello
```

That is the whole manifest. Two optional keys exist and neither is needed here:

- `custom.landing: <handle>` — which view opens. Without it, the first one
  alphabetically. Only useful from the second view on.
- `custom.init: other.js` — a different program file. Default is `main.js`.

There is **no** list of views, tables or scripts. Views are found by their own
header; the program is found by its name.

## `main.yaml` — the view

```yaml
$meta:
  kind: app-view
type: page
title: Hello
children:
  - type: toolbar
    children:
      - type: button
        label: Hello
        on:
          click: "main.js:hello"
  - type: text
    from: greeting
```

`$meta.kind: app-view` is what makes this a view — without it the runtime does
not find it and the app opens empty. The **file name is the handle**
(`main.yaml` → `main`), so it must be a slug: lowercase, digits, `-`, `_`.

`from: greeting` binds the text to a state key. Nothing declares that key; the
program writes it.

## `main.js` — the program

```js
let greetings = 0;

async function init() {
  vance.state.set('greeting', 'Ready — press Hello.');
}

function hello() {
  greetings++;
  vance.state.set('greeting', new Date().toISOString() + ' — Hello World (' + greetings + ')');
}
```

Plain top-level functions — **no `export`**. The source is evaluated as one
script, so a top-level function is reachable by name, which is what
`main.js:hello` in the view refers to.

`greetings` keeps its value between clicks: this is one program that keeps
running while the app is open, not one call per event.

`init()` writes something **visible** on purpose. If it only did invisible
setup you could not tell "the program ran" from "the program failed to load",
which is the first question you will ask.

## After editing

```
app_rebuild(folder="apps/hello")
```

It re-reads every view, reports what does not parse, and rewrites `_index.md`
with what the runtime actually found — the only place that answers "does the
runtime see my program?".
